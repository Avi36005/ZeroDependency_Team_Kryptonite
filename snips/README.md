# Snips

Captured output from `depx`, one file per scenario. Every file is real
terminal output with its exit code, generated by `make snips` — nothing here
is hand-written or edited, so if the tool changes and these do not, the
regeneration will say so.

Colour is stripped (`--no-color`) so the files stay readable in any viewer.
Run the same command in a terminal to see it in colour.

## Fixtures

`fixtures/` holds the small projects some snips run against. Each is a real
directory you can point `depx` at yourself:

- `faked-zero-dep/` — an empty manifest with a minified bundle and a
  licence-headered file pasted into `src/`
- `realistic-app/` — a plausible React app with a broken relative import, an
  invented package, two stdlib-replaceable dependencies, one stale dependency
  and three that a build tool loads
- `monorepo/` — a root with two packages under it

The no-manifest demo in `09` is generated into a temp directory at capture
time rather than committed. It has to be a Python file with no
`requirements.txt`, and leaving one in this repo would make **this** repo fail
its own `zero-dep` check — which is exactly what happened the first time, and
the test suite caught it.
